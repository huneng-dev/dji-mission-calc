# DJI 航拍航线计算器

一个用于计算 DJI 无人机航拍任务参数的纯前端网页工具。根据相机的物理光学参数（真实物理焦距与传感器尺寸）、飞行高度、重叠度和飞行速度，实时计算定时拍照间隔、地面覆盖幅宽和航线间距，并提供 3D 投影视锥图解。

> **特别说明**：目前仅验证了 **M3TD 广角** 机型。由于数码变焦与像元裁切机制原因，**GSD（地面分辨率）计算暂不准确**，请以拍照间隔和航线覆盖幅宽参数为主。

---

## 项目作用

- **算拍照间隔**：根据航向重叠率与飞行速度，计算出飞手所需的定时拍照间隔（秒/张）。
- **算覆盖幅宽**：计算单张照片在地面的航向覆盖长度（L）和旁向覆盖宽度（W）。
- **算航线间距**：根据旁向重叠率计算两条平行航线之间的横向间距（米）。
- **3D 视锥图解**：支持 360° 旋转查看镜头投影与地面重叠区域。

## 如何部署

本项目为纯静态单页，无后端、无 Python 依赖。

### 方式一：本地直接打开（最简单）
直接用电脑或手机浏览器双击打开 `index.html` 即可使用，无需启动任何服务器。

### 方式二：静态服务器或托管
将项目所有文件丢进任意 Web 服务器目录即可：
- **Nginx / Apache**：直接将文件放进站点根目录。
- **GitHub Pages / Cloudflare Pages / Vercel**：关联仓库直接发布，免构建命令。
